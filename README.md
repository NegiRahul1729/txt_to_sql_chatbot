## AI Text-to-SQL Chatbot

An AI-powered chatbot that converts natural language into SQL queries using Groq LLM.

## Features

- Natural Language to SQL
- SQLite Database Integration
- AI Query Generation
- Streamlit UI
- Real-time Query Execution

## Tech Stack

- Python
- Groq API
- Llama3
- Streamlit
- SQLite

## Installation

'''pip install -r requirements.txt'''
